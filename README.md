# Valida Studio

**Drag a few blocks. Ship a plugin.**

Valida is a visual builder for Minecraft server plugins.
Connect events, conditions and actions on a canvas, test them on a live sandbox server,
and export a `.jar` that drops straight into your `plugins` folder.

[Website](https://valida.studio/) · [Docs](https://valida.studio/docs) · [Changelog](https://valida.studio/changelog) · [Discord](https://discord.gg/validastudio)

</div>

## Why Valida

We're two friends from Austria who grew up on Minecraft. Running our own servers meant that every
new idea came with the same ritual: open the IDE, write Java, fight with build tools, restart the
server, repeat. At some point we were coding more plugins than we were playing.

Valida is the tool we always wanted: **if you can explain what your plugin should do, you should be
able to build it.**

## How it works

```
 ┌──────────────────────┐     ┌──────────────────┐     ┌──────────────────────┐
 │ Event                │ ──▶ │ Condition        │ ──▶ │ Action               │
 │ Player joins server  │     │ Is first join    │     │ Give starter kit     │
 └──────────────────────┘     └──────────────────┘     └──────────────────────┘
```

1. **Drag blocks onto the canvas.** Pick events, conditions and actions from the block library.
2. **Connect and configure.** Wire them together and fill in the details: an item, a message, a permission, a delay.
3. **Test and export.** Try it on a sandbox server, then download a standard `.jar` that runs like any hand-written plugin.

No Java. No `plugin.yml`. No lock-in. The export is a normal Paper plugin.
